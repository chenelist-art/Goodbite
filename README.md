# Stox

Stox is a stock, expiry and food cost app for small restaurants (demo with made-up data).

- **Live demo:** https://chenelist-art.github.io/Stox/
- `index.html` (this folder) is the app. It is the same file as `business/index.html`.
- `business/` has the source, tests, README and handoff note. After changing the source, run `python business/source/build.py` and copy `business/source/dist/index.html` to both `index.html` and `business/index.html`.
- `archive/goodbite-household/` is the old GoodBite household app, kept for reference only.
